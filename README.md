# کلید گرگ‌ومیش (Dusk-to-Dawn Switch)

این پروژه یک کلید خودکار است که با استفاده از میکروکنترلر **ATmega8** و سنسور نور **LDR**، لامپ را در تاریکی روشن و در روشنایی خاموش می‌کند. این دستگاه برای صرفه‌جویی در مصرف برق و اتوماسیون روشنایی حیاط، ویلا و مغازه بسیار مناسب است.

## ✨ ویژگی‌ها
- استفاده از هیسترزیس نرم‌افزاری برای جلوگیری از چشمک‌زدن لامپ در نور مرزی
- قابلیت تنظیم آستانه روشنایی در کد
- تأخیر زمانی برای جلوگیری از واکنش به تغییرات گذرا (مثل رد شدن ماشین)

## 🧰 قطعات مورد نیاز (BOM)
- میکروکنترلر ATmega8 (۱ عدد)
- سنسور LDR (۱ عدد)
- رله ۵ ولت (۱ عدد)
- ترانزیستور 2N3904 (۱ عدد)
- دیود 1N4007 (۱ عدد)
- مقاومت‌ها: ۱۰K (۲ عدد)، ۱K (۱ عدد)
- بردبورد، سیم جامپر و منبع تغذیه ۵ ولت

## 💻 نحوه کامپایل و پروگرام
کد موجود در فایل `main.c` با استفاده از کامپایلر **AVR-GCC** نوشته شده است. 
برای پروگرام کردن روی ATmega8، می‌توانید از نرم‌افزارهایی مثل **Proteus** (برای شبیه‌سازی) یا **AVRDUDESS** به همراه پروگرامر USBASP استفاده کنید.
